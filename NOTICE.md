# Notices

**Iron's Spellbooks** (upstream, by Iron431 and contributors) is
**All-Rights-Reserved**. This folder is a **clean-room reimplementation of the
mod's behaviour**, not a port of its files:

- No line of the original's Java code is read, translated or used. Horizon has
  no Java runtime; the native half is Rust written for Horizon's trait mod API.
- No item, block, model, texture, sound, recipe, lang file or other data from
  the original jar is copied. Every JSON file and every 16×16 texture in
  `content/` is generated by `tools/gen_content.py`, written for this port.
- The spell names (Firebolt, Heal, …) are ordinary English words used to
  describe the same public gameplay concepts; the numbers, summaries, art and
  the spellbook item names are this port's own choices.

What the port reproduces is the *described behaviour*: a mana pool raised by
mage gear, scrolls that cast a spell once, spellbooks that hold spell pages
with levels, and a core set of fire/ice/lightning/holy/ender/evocation spells.

The Horizon build pins `a85af177a82504f357ff10d5d40d0b7230e2ac32` and uses the
native trait mod API only (no injections, no patched Horizon source line).
